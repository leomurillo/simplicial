# FC3-A Bounded Information-Investment Theorem Candidate

Created: 2026-05-15

## Status

This is the first bounded FC3 theorem candidate.  It launches FC3 after the
bounded FC1 closure certificate and the FC2 filtered-source theorem, but it
does not claim an unbounded or row-universal mixed-row A0/J_infty
unification.

The safe theorem target is:

> finite abelian rows supply the zero-carry generated-subgroup baseline, the
> normalizer premium is paid exactly when transfer gain beats resource-weighted
> symmetry cost, and certified local rows add a separated filtered-carry ledger
> whose full residual cannot be replaced by support residual alone.

## Chosen Theorem

**FC3-A. Bounded split-ledger information-investment theorem.**  Let \(G\) be a
finite abelian character group with reciprocal support \(S\subset G\setminus
\{0\}\).  Let

```text
D_G(S) = <S> \ {0}
```

be the generated-subgroup descent support.  If a normalizer action `Gamma` is
declared, let

```text
D_G^Gamma(S) = <Gamma.S> \ {0}.
```

For certified local rows, assume a declared finite macrovariable skeleton from
FC1 and a filtered source class `[kappa]` from FC2.  Then the bounded
information-investment ledger is the separated vector

```text
J_split =
  generated_subgroup_descent
  + normalizer_symmetry_premium
  + PSL_depth_or_boundary_carry
  + full_filtered_carry
  + support_projection_carry
  + H4_visible_Fisher_shadow
  + H3_contraction_shadow
  + remaining_hidden_residual
  + resource_cost.
```

A scalar \(J_\infty\) is any nonnegative task-dependent weighting of this
ledger, with the convention that `full_filtered_carry` is the aggregate true
filtered residual and the H4/H3/remaining fields are its declared visibility
partition.  Scalarizations must therefore avoid accidental double-counting
unless the aggregate term is being used as a separate audit penalty.

## Claims

1. **Finite abelian baseline.**  In cyclic and finite abelian rows,
   `D_G(S)` is the unique minimum-resource support with zero projection,
   zero additive closure leakage, and zero descent-balance cost for generic
   reciprocal coefficients.  It is the zero-carry baseline for FC3.
2. **Normalizer premium.**  Among policies that must be `Gamma`-invariant,
   `D_G^Gamma(S)` is the unique minimum-resource support.  Relative to
   `D_G(S)`, it is selected exactly when

   ```text
   expected structural transfer gain
   >
   lambda_resource * (resource(D_G^Gamma(S)) - resource(D_G(S))).
   ```

3. **Local filtered carry is not support carry.**  For a certified local row,
   support residual is only a projection channel.  If full filtered residual
   survives and support residual is zero, any policy that prices carry only by
   support residual underprices the row by the full-filtered channel.
4. **First local ledger.**  On the bounded FC1 atlas for `F4[u]/(u^2)`, the
   imported tuple residual vector is

   ```text
   full/support/H4/H3/remaining = 1569/0/72/1470/27.
   ```

   Thus support pricing alone reports zero local carry, while the filtered
   source `[kappa]` still contributes `1569` atoms.  The tested H4/H3
   visibility partition satisfies `72 + 1470 + 27 = 1569`.

## Proof Skeleton

The first claim is B1/B2: Fourier supports inside a finite abelian subgroup
form a finite function algebra, so the generated subgroup is sufficient for
generic reciprocal support; any zero-structural-cost support containing `S`
must contain `<S>`.

The second claim is B3/B4.  Normalizer-invariant closure requires the subgroup
generated by the normalizer orbit.  Comparing the two scalar costs cancels the
common fixed-task terms and leaves exactly transfer gain versus
resource-weighted premium.

The third claim is FC2 plus the FC1 handoff.  The filtered source is
`[kappa]`; `K_CH`, H4, and H3 are visibility channels modulo Fisher-jet
kernels, not detectors of the full class by themselves.  Therefore support
projection can erase a nonzero filtered residual.

The fourth claim is the exact finite instantiation from the bounded
`F4[u]/(u^2)` FC1 atlas certificate.  It is a local cost ledger, not a
classification of arbitrary smooth invariants or all Fisher-volume-preserving
currents.

## Continuation: FC3-C

FC3-B is now scalarized by:

- `knowledge_base/fc3_weighted_mixed_row_theorem.md`.

FC3-C adds task-dependent nonnegative weights and extends the split ledger to
the bounded mixed-row A0/J_infty setting.  The scalarization is admissible only
when it does not collapse the local carry fields.  It must use either:

```text
lambda_full * full + lambda_support * support
```

as a full-filtered audit mode, or

```text
lambda_support * support
+ lambda_H4 * H4
+ lambda_H3 * H3
+ lambda_hidden * remaining
```

as a visibility-partition mode.  The two modes must not be summed as
independent masses unless `lambda_full` is explicitly an external audit
penalty, since `H4 + H3 + remaining = full`.

At current row scope the bounded mixed-row theorem says:

1. finite abelian factors use generated-subgroup descent as the zero-carry
   baseline;
2. normalizer saturation is selected exactly by the transfer-gain versus
   resource-premium inequality;
3. PSL depth is rowwise and governed by the existing carry-vs-depth thresholds;
4. local filtered carry is priced by the full/support/H4/H3/remaining ledger;
5. CRT separates filtered local carry rowwise, while task expectations and
   resource budgets may still couple the scalar objective.

## Boundaries

FC3-A does not claim:

- support residual `0` is full filtered closure;
- `K_CH` detects `Ext_CH` by itself;
- quotient sufficiency beyond the declared finite skeleton;
- arbitrary smooth invariant functions or all Fisher-volume-preserving
  currents are classified;
- learned-model transfer is proved by the finite atlas;
- Bures, transformer, FEP, primorial, or RH material belongs in the core proof
  spine.
