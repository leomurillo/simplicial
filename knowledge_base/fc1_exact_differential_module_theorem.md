# FC1-B Exact Finite-Sufficient Differential Module Theorem

Created: 2026-05-15

This note extends the FC1-A centroid classification from leading quadratic
jets to the exact finite-sufficient differential module.  The point is to make
the Nambu-Fisher Hamiltonian data algebraic enough that the Noether atlas
becomes a finite orbit/stabilizer computation at fixed jet order.

## Setup

Let \(R\) be a finite quotient ring, or a finite abelian output algebra with a
chosen normalizer packet action.  Let

```text
M = Delta_R^o
```

with Fisher volume \(\Omega_R^F\).  Fix a packet system \(\mathcal P\) on the
nontrivial character lines.  In the quotient-ring case, \(\mathcal P\) is the
primitive conductor packet system with CRT/Hayes/Galois normalizer
\(\Gamma_R\).

For a finite jet order \(k\ge 0\), define a finite **natural observation map**

```text
Phi_{R,k}: M -> Y_{R,k}
```

whose coordinate functions consist of:

1. quotient sufficient statistics \(R\to R/\mathfrak d\), equivalently fiber
   probabilities for the quotient sigma algebra;
2. primitive packet energies
   \[
   E_{\mathfrak d}(p)=\frac12\|\Pi_{\mathfrak d}(p-p_*)\|_{F,*}^2;
   \]
3. packetwise Fisher-orthogonal flag coordinates when a particular NZSBTL
   internal flag is part of the chosen atlas;
4. for \(k>0\), quotient-character adjacency orbit coordinates through order
   \(k\), i.e. the finite list of \(\Gamma_R\)-orbit representatives of
   active \(A_\eta^{\mathfrak f,\mathfrak e}\) coefficients and their
   Fisher-jet shadows retained by the atlas.

The coordinate set is finite because \(R\), the packet system, and the
order-\(k\) adjacency atlas are finite.

Define the **finite-sufficient macrovariable algebra**

```text
N_{R,k} = Phi_{R,k}^* C^\infty(Y_{R,k}).
```

Thus a macrovariable \(C\) is in \(\mathcal N_{R,k}\) exactly when it factors
through the finite quotient/packet/adjacency observations retained by the
atlas:

```text
C = F o Phi_{R,k}
```

for some smooth \(F\) on \(Y_{R,k}\).  Define the finite-sufficient
differential module

```text
Omega^1_{R,k,nat} = Phi_{R,k}^* Omega^1(Y_{R,k}).
```

Equivalently, if \(y_1,\ldots,y_m\) are the coordinates of \(\Phi_{R,k}\),
then

```text
Omega^1_{R,k,nat}
  = span_{N_{R,k}} {dy_1, ..., dy_m}.
```

The **exact** finite-sufficient differential module is

```text
d N_{R,k} = {dC : C in N_{R,k}} subset Omega^1_{R,k,nat}.
```

## Theorem

**FC1-B1. Exact finite-sufficient differential module theorem.**

1. Every exact finite-sufficient Hamiltonian differential is an element of the
   finite-rank module \(\Omega^1_{R,k,nat}\):
   \[
   d(F\circ\Phi_{R,k})=\Phi_{R,k}^*(dF).
   \]
2. Conversely, a one-form \(\alpha\in\Omega^1_{R,k,nat}\) is locally an exact
   finite-sufficient Hamiltonian differential if and only if the corresponding
   one-form \(\bar\alpha\) on \(Y_{R,k}\) is closed on the finite observation
   image.  On simply connected coordinate patches of \(Y_{R,k}\), this is
   equivalent to \(\alpha=d(F\circ\Phi_{R,k})\) for some local smooth
   \(F\).
3. For simplectic Hamiltonian data
   \[
   \mathbf C=(C_1,\ldots,C_{Q-2}),\qquad C_i\in\mathcal N_{R,k},
   \]
   the exact decomposable Nambu current satisfies
   \[
   P_{\mathbf C}
   =
   dC_1\wedge\cdots\wedge dC_{Q-2}
   \in
   \bigwedge^{Q-2}\Omega^1_{R,k,nat}.
   \]
   Hence every exact decomposable Fisher-volume current generated by
   finite-sufficient Hamiltonian data is represented inside the exterior
   algebra of this finite module.
4. If a normalizer element \(\gamma\in\Gamma_R\) acts on \(Y_{R,k}\) and sends
   the Hamiltonian tuple to
   \[
   \gamma^*\mathbf C=A_\gamma\mathbf C+\text{constant}
   \]
   for an invertible \((Q-2)\times(Q-2)\) matrix \(A_\gamma\), then
   \[
   \gamma^*P_{\mathbf C}=\det(A_\gamma)P_{\mathbf C}.
   \]
   Therefore the determinant character in Paper 13's adjacency-Noether theorem
   is computed inside the finite observation atlas.

## Proof

Let \(C=F\circ\Phi_{R,k}\).  The chain rule gives

```text
dC = d(F o Phi_{R,k}) = Phi_{R,k}^*(dF).
```

Writing \(dF=\sum_j (\partial_j F)dy_j\) on \(Y_{R,k}\) gives

```text
dC = sum_j ((partial_j F) o Phi_{R,k}) d(Phi_{R,k}^* y_j),
```

so \(dC\) lies in the finite-rank \(\mathcal N_{R,k}\)-module generated by
the coordinate differentials \(dy_j\).  This proves the first claim.

For the converse, any \(\alpha\in\Omega^1_{R,k,nat}\) has the form
\(\alpha=\Phi_{R,k}^*\bar\alpha\) for some one-form \(\bar\alpha\) on the
finite observation space, at least after restricting to a coordinate patch and
quotienting out redundant coordinates on the image.  If
\(\bar\alpha=dF\), then \(\alpha=d(F\circ\Phi_{R,k})\).  Conversely, if
\(\alpha=d(F\circ\Phi_{R,k})\), then \(\bar\alpha=dF\) on the observation
image, so it is closed.  On a simply connected coordinate patch, the Poincare
lemma gives a local primitive for every closed \(\bar\alpha\).  This proves
the exactness criterion.

The third claim is formal.  If each \(C_i\in\mathcal N_{R,k}\), then each
\(dC_i\in\Omega^1_{R,k,nat}\) by the first claim.  Wedges of module elements
lie in the exterior power of the module:

```text
dC_1 wedge ... wedge dC_{Q-2}
  in wedge^{Q-2} Omega^1_{R,k,nat}.
```

Finally, suppose \(\gamma^*\mathbf C=A_\gamma\mathbf C+\text{constant}\).
Differentiating removes constants:

```text
gamma^* dC_i = sum_j (A_gamma)_{ij} dC_j.
```

Taking the wedge over \(i=1,\ldots,Q-2\) multiplies it by
\(\det(A_\gamma)\).  This proves the determinant-character statement.
\(\square\)

## Extension Of The First-Current Corollary

FC1-A proved the leading quadratic case:

```text
C_i(h) = Q_{B_i}(h) + O(||h||^3)
```

forces the leading current to be a wedge of packet-energy covectors.
The theorem above replaces that leading-order statement by an exact local
statement:

```text
C_i in N_{R,k}
    => dC_i in Omega^1_{R,k,nat}
    => P_C in wedge^{Q-2} Omega^1_{R,k,nat}.
```

So the naturality claim no longer depends only on the first Taylor coefficient.
At any fixed finite adjacency/Fisher-jet order \(k\), exact decomposable
currents generated by finite-sufficient Hamiltonians live in a finite exterior
differential module.

## Noether Atlas Reduction

At fixed \(k\), choose coordinates \(y_1,\ldots,y_m\) for \(Y_{R,k}\).  The
normalizer \(\Gamma_R\) acts by a finite matrix/permutation representation on
the coordinate list:

```text
rho_k: Gamma_R -> GL(Y_{R,k}).
```

For a finite polynomial jet order \(r\), let

```text
J^r N_{R,k}
```

be the finite-dimensional space of degree-\(\le r\) Taylor jets of functions
on \(Y_{R,k}\).  Hamiltonian tuples have jets in

```text
(J^r N_{R,k})^{Q-2}.
```

The Noether atlas through orders \((k,r)\) is therefore the finite linear
algebra problem:

1. enumerate \(\Gamma_R\)-orbits of tuple support patterns or chosen finite
   coefficient sets in \((J^r N_{R,k})^{Q-2}\);
2. compute stabilizers
   \[
   \operatorname{Stab}_{\Gamma_R}(\mathbf C)
   =
   \{\gamma:\gamma^*\mathbf C=A_\gamma\mathbf C+\text{constant}\};
   \]
3. compute determinant characters \(\det(A_\gamma)\) on stabilizers;
4. compute the induced action on
   \[
   P_{\mathbf C}\in \bigwedge^{Q-2}\Omega^1_{R,k,nat};
   \]
5. attach Paper 11 closure-defect operators
   \(D_m^S\) and FC2 filtered residual classes \([\kappa]\) to each orbit.

There can still be continuous coefficient strata if arbitrary real smooth
functions \(F_i\) are allowed.  The finite claim is the structural one: once
the finite observation map \(\Phi_{R,k}\), a polynomial jet order \(r\), and a
coefficient field or support skeleton are fixed, the Noether atlas is an
ordinary finite orbit/stabilizer/rank computation.

## What This Moves

Before this theorem, FC1-B could still be read as a philosophy of "natural
Hamiltonians."  Now the exact decomposable part is a module statement:

```text
finite observations -> finite differential module -> exterior Nambu currents.
```

The remaining nontrivial proof burden is not to justify the module.  It is to
run the finite Noether atlas and then connect off-centroid failure to the
Paper 11 carry operators and the FC2 filtered source class.
