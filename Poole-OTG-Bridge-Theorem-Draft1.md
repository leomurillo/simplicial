1. Every fixed Poole rule has an exact open-quantum lift whose decoherent

The note does not prove that Poole dynamics is quantum gravity. It proves the

## Theorem A: Exact Decoherent Quantum-Channel Lift

Let `X` be any finite configuration space and let `F : X -> X` be any
deterministic update. Let `H_X = C^X` with computational basis `{|x> : x in X}`.
Define Kraus operators

```text
A_x = |F(x)><x|, for x in X.
```

Define the channel

```text
E_F(rho) = sum_x A_x rho A_x^*.
```

Then:

1. `E_F` is completely positive and trace preserving.
2. On diagonal density matrices, `E_F` is exactly the classical deterministic
   update.
3. Off-diagonal coherences are killed by the channel.

### Proof

Complete positivity is immediate from the Kraus form.

For trace preservation,

```text
sum_x A_x^* A_x
  = sum_x |x><F(x)|F(x)><x|
  = sum_x |x><x|
  = I.
```

Let a classical probability distribution `p` be embedded as the diagonal state

```text
D(p) = sum_x p_x |x><x|.
```

Then

```text
E_F(D(p))
  = sum_x A_x (sum_u p_u |u><u|) A_x^*
  = sum_x p_x |F(x)><F(x)|.
```

The coefficient of `|y><y|` is therefore

```text
sum_{x : F(x)=y} p_x,
```

which is exactly the pushforward of `p` along `F`.

For `u != v`,

```text
E_F(|u><v|) = 0,
```

because each Kraus term requires the same index to match both `u` and `v`.
Thus this lift is an exact decohering quantum channel whose classical face is
the original Poole update. QED.

## Corollary A1: The T7 Classical-to-Quantum Bridge

The classical probability simplex on `X` is the decoherent face of density
matrices on `H_X`. The complex amplitude space supplies phases and coherences;
the Born/dephasing projection returns classical probabilities.

Thus a Poole rule already has a clean mathematical path from classical finite
dynamics to quantum language:

```text
complex amplitudes / density matrices
        -> dephase or restrict to diagonal states
        -> classical probability simplex
        -> deterministic Poole update
```

This closes the basic T7 gap: the classical rule is not outside quantum

The corollary is also a warning. The channel above is the minimal lift. It

Lindblad-type dynamics whose dephased restriction recovers the Poole rule while
the off-diagonal sector carries testable additional structure.

## Theorem B: Exact Reversible Dilation

Let `X = {0,1}^N` and let `F : X -> X` be any deterministic Boolean update.
Let the environment register also have basis `X`. Define

```text
U_F |x>|y> = |x>|y xor F(x)>.
```

Then `U_F` is unitary. In particular,

```text
U_F |x>|0> = |x>|F(x)>.
```

If the input is a diagonal classical mixture and the first register is traced
out, the second register has exactly the classical output distribution.

### Proof

For each fixed `x`, the map

```text
y -> y xor F(x)
```

is a bijection on `X`. Therefore `(x,y) -> (x, y xor F(x))` is a bijection on
`X x X`. A bijection of a computational basis extends linearly to a unitary
operator.

Starting from `|x>|0>`, the output is `|x>|F(x)>`. For a diagonal mixture

```text
sum_x p_x |x><x| tensor |0><0|,
```

the second marginal after applying `U_F` is

```text
sum_x p_x |F(x)><F(x)|,
```

which is the same pushforward distribution as in Theorem A. QED.

## Corollary B1: Irreversibility Is an Environment Statement

If `F` is not injective, there is no same-space unitary satisfying

```text
U |x> = |F(x)> for all x.
```

Indeed, if `F(x)=F(x')` with `x != x'`, then a unitary would send two orthogonal
basis vectors to the same vector, contradicting preservation of inner products.

Thus non-injective Poole dynamics can be quantum-lifted exactly only as an open
system or as a reversible system with an environment/history register. This is
the precise bridge from classical irreversible cellular dynamics to the
quantum/decoherence story.

For a finite-radius Boolean cellular rule, the dilation can be implemented by
standard reversible Boolean circuitry with work registers. The exact circuit
depth and best locality-preserving schedule are Poole-specific engineering
questions, but finite exact reversibilization is automatic.

## Theorem C: Exact Closure and Leakage Test

Let `Q : X -> Y` be any proposed retained observable sector. Examples include
local neighbor count, center state plus neighbor count, density, patch type,
Betti data, current class, or any finite feature map.

The sector `Q` is closed under `F` iff there exists a map

```text
G : Y -> Y
```

such that

```text
Q o F = G o Q.
```

Equivalently, `Q` is closed iff

```text
Q(x) = Q(x') implies Q(F(x)) = Q(F(x'))
```

for all configurations `x,x'`.

If this condition fails, then there is an exact boundary-leakage witness:

```text
Q(x) = Q(x') but Q(F(x)) != Q(F(x')).
```

### Proof

If `G` exists and `Q(x)=Q(x')`, then

```text
Q(F(x)) = G(Q(x)) = G(Q(x')) = Q(F(x')).
```

Conversely, suppose the implication holds. Define `G` on the image of `Q` by
choosing any `x` with `Q(x)=y` and setting

```text
G(y) = Q(F(x)).
```

The implication ensures this definition is independent of the chosen
representative `x`. Extend `G` arbitrarily outside the image of `Q` if needed.
Then `Q o F = G o Q`. QED.

## Theorem D: Current/Blind-Spot Audit for Transition Data

Let `K` be a finite Markov transition matrix on a state set `Y`, and let `pi` be
a stationary distribution with positive support. Define the adjoint in
`L^2(pi)` by

```text
(K^*)(x,y) = pi_y K(y,x) / pi_x.
```

Define

```text
S = (K + K^*) / 2,
A = (K - K^*) / 2.
```

Then:

1. `S` is the time-symmetric part of the transition operator.
2. `A` is the antisymmetric current/arrow part.
3. Detailed balance holds iff `A = 0`.
4. The stationary edge current

```text
J(x,y) = pi_x K(x,y) - pi_y K(y,x)
```

is antisymmetric and has zero stationary divergence.

### Proof

The definitions give `S^* = S` and `A^* = -A`, so `S` is symmetric and `A` is
antisymmetric in `L^2(pi)`. Detailed balance is exactly

```text
pi_x K(x,y) = pi_y K(y,x)
```

for all `x,y`, which is equivalent to `K=K^*`, hence `A=0`.

For stationary divergence,

```text
sum_y J(x,y)
  = pi_x sum_y K(x,y) - sum_y pi_y K(y,x)
  = pi_x - pi_x
  = 0,
```

using row-stochasticity and stationarity. QED.
