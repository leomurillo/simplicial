## 1. Detector Topology

Work first on the log-side detector class
\[
\mathcal D_{\delta,0}
=
\left\{
G\in C(\mathbb R):
\|G\|_{\delta,0}
:=
\sup_{u\in\mathbb R}
e^{(1+\delta)|u|}|G(u)|<\infty
\right\},
\qquad \delta>0.
\]

Derivative seminorms may be added later when partial summation or smooth CRT
approximation requires them, but the double-cutoff theorem itself only uses
\(J=0\).  Gaussian detectors, and the Gaussian-damped Poisson detectors used
in the existing window probes, lie in every \(\mathcal D_{\delta,0}\) after
the fixed log-side normalization used by the Weil test.

The topology is the norm topology generated by \(\|\cdot\|_{\delta,0}\), or
the corresponding inductive family when several \(\delta\)'s are used.
Bounded sets in a fixed \(\mathcal D_{\delta,0}\) have a single exponential
majorant
\[
|G(u)|\le C_B e^{-(1+\delta)|u|}.
\]

This is intentionally narrower than the full Weil test space.  It is enough
for the local Poisson-window detector argument because Gaussian and
Gaussian-damped Poisson convolution-square windows separate negative valleys
of
\(\operatorname{Im}m_B(x+iy)\).

## 2. Absolute Convergence

**Lemma 2.1 (prime-power absolute convergence).**  
If \(G\in\mathcal D_{\delta,0}\), then
\[
\sum_p\sum_{r\ge1}(\log p)|G(r\log p)|<\infty .
\]
The same holds for the reflected term \(G(-r\log p)\).

*Proof.*  For \(u=r\log p\ge0\),
\[
|G(r\log p)|
\le
\|G\|_{\delta,0}p^{-r(1+\delta)}.
\]
Thus
\[
\sum_p\sum_{r\ge1}(\log p)|G(r\log p)|
\le
\|G\|_{\delta,0}
\sum_p(\log p)\sum_{r\ge1}p^{-r(1+\delta)}.
\]
The inner sum is
\[
{p^{-(1+\delta)}\over 1-p^{-(1+\delta)}}.
\]
For large \(p\) this is \(O(p^{-1-\delta})\), and
\[
\sum_p { \log p\over p^{1+\delta}}<\infty
\]
by comparison with the convergent integer series
\(\sum_{m\ge2}(\log m)m^{-1-\delta}\).  The reflected term is identical
because the topology controls both tails. \(\square\)

## 3. Double-Cutoff Theorem

For axis cutoff \(p_n\), occupation cutoff \(K_n\), and Dirichlet cutoff
\(M_n\), define
\[
\operatorname{VM}_{n,K_n,M_n}(G)
=
\sum_{\substack{p\le p_n\\1\le r\le K_n\\p^r\le M_n}}
(\log p)G(r\log p).
\]

**Theorem 3.1 (Double-Cutoff Poisson-Window Recovery for detector kernels).**  
Let \(G\in\mathcal D_{\delta,0}\), and let
\[
p_n\to\infty,\qquad K_n\to\infty,\qquad M_n\to\infty.
\]
Then
\[
\operatorname{VM}_{n,K_n,M_n}(G)
\longrightarrow
\sum_p\sum_{r\ge1}(\log p)G(r\log p).
\]
The convergence is locally uniform on bounded subsets of
\(\mathcal D_{\delta,0}\).  Applying the same statement to the reflected
kernel gives the completed finite-place distribution
\[
\sum_p\sum_{r\ge1}
(\log p)\left(G(r\log p)+G(-r\log p)\right).
\]

*Proof.*  Let
\[
a_{p,r}(G)=(\log p)G(r\log p).
\]
By Lemma 2.1, \(\sum_{p,r}|a_{p,r}(G)|\) is absolutely convergent.  The
finite cutoff indicator
\[
1_{\{p\le p_n,\ r\le K_n,\ p^r\le M_n\}}
\]
converges pointwise to \(1\) on the countable index set of prime powers.  The
absolute-convergence majorant is summable, so dominated convergence gives the
limit.

For uniformity on a bounded set \(B\subset\mathcal D_{\delta,0}\), use the
common majorant
\[
|a_{p,r}(G)|
\le
C_B(\log p)p^{-r(1+\delta)}.
\]
The tail of this majorant tends to zero independently of \(G\in B\).  This
proves locally uniform convergence. \(\square\)

## 5. Siegel-Walfisz-Safe Diagonal

The double-cutoff theorem above is already closed by absolute convergence.
The Siegel-Walfisz-safe diagonal enters when one insists on comparing the
occupation-decorated observable with the character-expanded CRT shadow.
It is legitimate as an existence-scale statement, but only with the correct
split.

Fix \(\beta>0\) and put
\[
M_n=\exp(P_n^\beta).
\]
Then for every \(A>1/\beta\),
\[
P_n\le(\log M_n)^A.
\]
Consequently, for dyadic blocks \(X\ge M_n\), every modulus \(q\mid P_n\)
satisfies
\[
q\le P_n\le(\log X)^A,
\]
so the classical Siegel-Walfisz theorem supplies individual character
uniformity for the character-expanded CRT shadow on those high blocks.

The low blocks \(X<M_n\) are not covered by Siegel-Walfisz when the modulus is
as large as \(P_n\).  In the detector theorem this causes no loss because:

1. the occupation-decorated single-axis terms with \(p\le p_n\) are already
   exact upstairs;
2. the omitted axis tail \(p>p_n\) is bounded by
   \[
   C\sum_{p>p_n}\sum_{r\ge1}(\log p)p^{-r(1+\delta)}
   \to0;
   \]
3. the high Dirichlet tail \(p^r>M_n\) is bounded by the same summable
   exponential majorant.

Thus the safe diagonal proves an existence-scale CRT realization only after
the low-scale occupation terms and the analytic tail are separated.  It does
not prove a natural finite-row efficiency theorem.

## 6. Natural-Scale BV Audit

Paper 43's hybrid \(r_0=5\) route is promising but not closed as a rigorous
input for this theorem.  The draft itself identifies the obstruction.

The exact missing polishing tasks are:

1. **Smoothing-error scaling.**  Re-derive the iterated-completion bound with
   the exact smooth cutoff dependence; the current proof absorbs terms into
   Schwartz decay and then needs them again for the exponent.
2. **Major/minor arc split.**  Separate the \(\mathbf k\)-sum after iterated
   completion; major arcs must produce the main term through Siegel-Walfisz
   and minor arcs must be controlled by the bilinear bound.
3. **Smooth-divisor count.**  Replace the crude divisor count for
   \(d\mid P_n,\ d\le X^\theta\) by a de Bruijn/Hildebrand-Tenenbaum scale
   estimate precise enough not to corrupt \(\theta_0\).
4. **Uniformity in \(n\).**  Show that constants are independent of the
   ambient primorial level once the fixed \(r_0=5\) completion has been made.
5. **Exponent reconciliation.**  The draft derives mutually incompatible
   intermediate values for \(\theta_0\) (below \(1/2\), above \(1\), and the
   intended \(0.538\)).  The \(0.538\) value cannot be used until the averaged
   error normalization and the lost factors are written without handoff
   ambiguity.
