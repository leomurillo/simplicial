# Note: Poisson-Window CRT Generation

Random suffix: `K7mQ2`

Mission: push the Poisson-Window Recovery Theorem one layer deeper.

Previous result:
\[
{\mathfrak P}_{\phi,y}(\Xi)
=
\int_{\mathbb R}\phi(x)\operatorname{Im}m_B(x+iy)\,dx
\]
detects CM Poisson Monotonicity.  If these window functionals are
nonnegative for all nonnegative windows, then RH follows.

This note proves the finite harmonic-generation part:

\[
\boxed{
\text{primorial CRT character systems can approximate the required local
Poisson windows.}
}
\]

So the remaining gap is not visibility of the window.  It is arithmetic
sign transport: the recovered Noether-Weil form must put the correct divisor
measure on these windows.

## 1. Window Class

Fix a compact height interval
\[
I_T=[-T,T].
\]

For \(x_0\in I_T\), \(y>0\), and \(\sigma>0\), define a localized
Poisson-Gaussian detector
\[
W_{x_0,y,\sigma}(x)
=
\left(
{y\over (x-x_0)^2+y^2}
+
{y\over (x+x_0)^2+y^2}
\right)
\exp\!\left(-{(x-x_0)^2\over 2\sigma^2}\right)
+
\left(
{y\over (x+x_0)^2+y^2}
+
{y\over (x-x_0)^2+y^2}
\right)
\exp\!\left(-{(x+x_0)^2\over 2\sigma^2}\right).
\]

The symmetric duplication makes the window compatible with the even
\(K\)-structure of \(\Xi(z)\).  Any off-boundary zero at \(x_0+i\beta\)
is detected by choosing \(0<y<\beta\) close to \(\beta\) and \(\sigma\) small.

The exact shape is not sacred.  What matters is:

1. \(W\ge0\);
2. \(W\) is smooth on the finite height interval;
3. \(W\) localizes around \(\pm x_0\);
4. translates and dilates of these windows separate points.

## 2. CRT Fourier Basis on Primorial Rows

Let
\[
P_n=p_n\#.
\]

The additive characters of \(\mathbb Z/P_n\mathbb Z\) are
\[
\chi_k(r)=\exp(2\pi i k r/P_n),\qquad k=0,\ldots,P_n-1.
\]

After identifying a finite height interval \(I_T\) with a periodic circle of
length \(2T\), these characters become the usual Fourier modes
\[
e_k(x)=\exp\!\left(2\pi i k {x+T\over 2T}\right).
\]

Because \(P_n\to\infty\), the primorial rows supply arbitrarily fine Fourier
resolution.  The \(K\)-even real sector is obtained by taking cosine pairs
\[
\cos\!\left(2\pi k{x+T\over 2T}\right),
\]
or equivalently by imposing \(c_{-k}=\overline{c_k}\).

## 3. Fejer Approximation Theorem

**Theorem 3.1 (finite CRT window generation).**  
Let \(W\in C(I_T)\) be \(2T\)-periodized continuously.  Let
\(\sigma_K W\) be its \(K\)-th Fejer mean:
\[
\sigma_K W(x)
=
\sum_{|k|\le K}
\left(1-{|k|\over K+1}\right)c_k e^{\pi i k x/T},
\]
where \(c_k\) are the Fourier coefficients of \(W\).

Then
\[
\|\sigma_K W-W\|_{\infty,I_T}\to0
\quad(K\to\infty).
\]

Moreover, if \(W\ge0\), then \(\sigma_KW\ge0\) for every \(K\), because
\(\sigma_KW\) is convolution with the positive Fejer kernel.

Choose \(K_n\le (P_n-1)/2\) with \(K_n\to\infty\).  Since the modes
\(|k|\le K_n\) are contained in the character algebra of
\(\mathbb Z/P_n\mathbb Z\), the primorial CRT system approximates \(W\)
uniformly:
\[
\|\sigma_{K_n}W-W\|_\infty\to0.
\]

If \(W\) is \(K\)-even, each \(\sigma_{K_n}W\) is \(K\)-even.

*Proof.*  This is Fejer's theorem on the circle.  The only primorial input is
that \(P_n\to\infty\), so the finite character algebra contains larger and
larger symmetric blocks of Fourier modes.  The \(K\)-even assertion follows
from \(c_{-k}=\overline{c_k}\). \(\square\)

## 4. What This Closes

The local Poisson windows are not invisible to the finite arithmetic carrier.
They are generated by ordinary CRT characters on primorial rows.

Thus the Poisson-Window Recovery Theorem splits into two independent parts:

### A. Harmonic Generation [closed]

For every local detector \(W_{x_0,y,\sigma}\) and every tolerance
\(\epsilon>0\), there exist a primorial row \(P_n\) and a positive
\(K\)-even finite character polynomial \(W_n\) such that
\[
\|W_n-W_{x_0,y,\sigma}\|_{\infty,I_T}<\epsilon.
\]

This is the theorem above.

### B. Arithmetic Sign Transport [open]

One must still prove that the finite Noether-Weil recovery maps do not merely
generate the window shape, but generate the correct divisor-weighted
functional:
\[
\mathcal Q_n(\mathscr R_n W_n)
\longrightarrow
{\mathfrak P}_{W,y}(\Xi)
\]
or, equivalently, the corresponding completed Weil explicit-formula
functional on the same window class.

This is exactly the content of Paper 22's Lemma 8.1 package:

1. CRT/Ramanujan/Mobius isolation of the finite observable;
2. occupation lift from squarefree axes to prime powers;
3. double cutoff convergence;
4. primorial character uniformity;
5. density in the completed Weil topology.

## 5. Safe Diagonal Versus Natural Scale

For a fixed Gaussian/Poisson window, the double-cutoff tail is harmless: its
log-Fourier transform has rapid or exponential decay.  Therefore the cutoff
commutation part of Paper 22 Lemma 8.1b is closed for these windows.

There are two possible recovery scales:

1. **Siegel-Walfisz-safe diagonal.**  Let the Dirichlet cutoff \(M_n\) grow so
   fast that every divisor \(q\mid P_n\) lies in the Siegel-Walfisz range
   \(q\le(\log M_n)^A\).  This gives classical pointwise character
   uniformity, but at enormous scale.
2. **Natural primorial scale.**  Keep \(M_n\) comparable to the finite row.
   Then Siegel-Walfisz is insufficient, and one needs the primorial
   Bombieri-Vinogradov / hybrid completion machinery of Paper 43.

So the safe diagonal gives an existence route for fixed windows once the
algebraic occupation-lift is written out.  The natural-scale theorem is the
hard analytic-number-theory route.

## 6. The New Sharp Target

The remaining theorem should now be stated as:

\[
\boxed{
\textbf{Arithmetic Poisson-Window Recovery Theorem.}
}
\]

For every \(K\)-even Poisson-Gaussian detector \(W\), choose finite Fejer/CRT
approximants \(W_n\).  Then the primorial Noether-Weil recovery maps satisfy
\[
\lim_{n\to\infty}
\mathcal Q_n(\mathscr R_n W_n)
=
{\mathfrak P}_{W,y}(\Xi),
\]
with the completed gamma/K normalization.

If this theorem holds and \(\mathcal Q_n\ge0\), then
\[
{\mathfrak P}_{W,y}(\Xi)\ge0
\]
for every detector \(W\).  Since Gaussian detectors separate negative
valleys of \(u_B=\operatorname{Im}m_B\), CM Poisson Monotonicity follows.
