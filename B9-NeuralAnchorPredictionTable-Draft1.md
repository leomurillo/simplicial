\[
\boxed{
\text{the B-series must now distinguish route variables from continuous precision variables.}

> Does scalar surprise fail?

It is:

> Does the brain contain operation-specific routing variables that cannot be
> reduced to continuous precision-weighted active inference?

## Rival Hypotheses

### H1. Bucket-Routing Hypothesis

Prediction errors are routed through operation-specific gates. The same scalar
surprise, and even the same approximate precision, can produce distinct neural
operations:

| Error source | Operation |
|---|---|
| retained drift | reweight |
| bad chart | rechart |
| missing interaction | close |
| temporal asymmetry | predict current |
| underdetermination | sample |
| capacity overload | compress or externalize |
| stochastic variation | suppress |
| forbidden structure | inhibit |
| calibration failure | recalibrate |

The bucket hypothesis predicts neural variables that forecast **which
operation** will occur, above and beyond scalar error, expected value, precision,
and action cost.

### H0. Precision-Active Inference Rival

The same behavior is produced by continuous precision-weighted active inference.
There are no discrete route variables. Apparent buckets are a human-readable
coarse graining of:

- precision matrices;
- policy precision;
- expected information gain;
- risk and preference gradients;
- solenoidal flow;
- action and memory costs.

Under H0, once these continuous variables are modeled well, bucket labels should
add little or no predictive or causal power.

## Minimal Neural Experiments

### B9-E1. Content-Specific Prediction Error Routing

**Task.** Train animals or humans on multi-feature outcome predictions where
identity, timing, value, and sensory content can be violated independently.
Match scalar error and reward prediction error across conditions.

**Record.** Midbrain dopamine ensembles, striatum, orbitofrontal cortex, and
behavioral update choice.

**Bucket win.** A population error-content axis predicts whether the subject
reweights, samples, closes a new association, or suppresses, after controlling
for scalar RPE, value, and precision estimates.

**Precision-rival win.** Route choice is fully predicted by continuous
precision/value variables; decoded content adds no independent route
information.

---

### B9-E2. Chart Versus Retained Update in Navigation

**Task.** Use navigation environments with matched sensory surprise but
different causes:

1. small parametric drift in cue reliability;
2. geometric deformation requiring map recharting;
3. stable missing interaction cue;
4. stochastic cue noise.

**Record.** Place cells, grid cells, hippocampal sharp-wave replay, LC/NE,
behavioral exploration, and policy changes.

**Bucket win.** Retained drift, chart remapping, packet learning, and noise
suppression are separable neural transitions under matched scalar surprise.

**Precision-rival win.** A continuous precision/volatility model explains both
neural remapping and behavior without route variables.

---

### B9-E3. Current Versus Symmetric Transition Evidence

**Task.** Construct sequence environments with the same stationary occupancy
and symmetric transition statistics, but opposite temporal currents. Include a
detailed-balance null.

**Record.** Hippocampal sequence activity, theta phase organization,
cortico-striatal transition coding, and action selection.

**Bucket win.** A signed temporal-current axis predicts forward/reverse
behavior after controlling for symmetric transition evidence.

**Precision-rival win.** Solenoidal or continuous temporal-flow terms explain
all direction-sensitive behavior without discrete current admission.

---

### B9-E4. Governed Competence

**Task.** Present cues that are equally predictive but differ in whether using
them is allowed, punished, socially forbidden, or task-invalid.

**Record.** Predictive cue representation, prefrontal inhibitory control,
basal-ganglia gating, autonomic/affective signals, and behavior.

**Bucket win.** The forbidden cue is neurally represented as predictive while
the action/update gate is inhibited. Competence and refusal are separable.

**Precision-rival win.** A continuous risk/preference model fully explains the
suppression, with no independent represented-but-blocked route variable.

---

### B9-E5. Ledger Recalibration

**Task.** Introduce distribution shifts that preserve local feature quality but
break calibration or exchangeability. Compare them to ordinary local feature
drift and random noise.

**Record.** Confidence, pupil/LC/NE, ACC, hippocampal context cells, behavioral
reset, and recalibration time.

**Bucket win.** Exchangeability break produces a discrete reset/recalibration
state that predicts later coverage recovery.

**Precision-rival win.** All effects are explained by gradual volatility or
precision adaptation.

## Model Comparison Standard

B9 should not accept informal neural resonance. Each experiment should compare:

1. **Scalar baseline.** Surprise or reward prediction error only.
2. **Continuous precision rival.** Precision, volatility, expected information
   gain, policy precision, risk, and cost.
3. **Bucket route model.** Same continuous variables plus route-specific latent
   state or gate.
4. **Perturbation model.** Causal interventions on candidate route circuits.

The bucket model earns credit only if it improves:

- held-out route prediction;
- cross-task route generalization;
- noise false-admission control;
- perturbational double dissociation;
- mediation beyond continuous precision variables.

## What Would Change the B-Series

### If H0 wins

If continuous precision-active inference predicts neural routes and behavior as
well as the bucket model, then the B-series should weaken its claim:

\[
\boxed{
\text{buckets are an operational discretization of continuous precision control.}
}
\]

That would still be useful, but it would not be a distinct neural architecture.

### If H1 wins

If route variables generalize across tasks and survive precision controls, then
the B-series earns the stronger claim:

\[
\boxed{
\text{animal brains contain route-specific prediction-error management variables.}
}
\]

That would make the buckets more than vocabulary.

### If the result is mixed

The likely outcome is mixed:

- content, noise, and governance may have relatively discrete route signatures;
- chart and current may be better understood as continuous geometry/flow;
- ledger and capacity may be algorithmic-level descriptions rather than local
  neural modules.

This is not a loss. It would give the B-series a sharper biological shape.
