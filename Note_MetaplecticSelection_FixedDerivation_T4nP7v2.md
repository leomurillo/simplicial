## 4. Tate-Weil normalization explicit

**Convention (Tate-Weil).** We use Planck constant $\hbar = 1/(2\pi)$,
equivalently the Heisenberg commutator $[\hat x, \hat p] = i/(2\pi)$, where
$\hat x$ is multiplication and $\hat p = -i\hbar \partial_x$.

In this normalization:
\[
\hat a = \sqrt{\pi}\,\hat x + \frac{i}{\sqrt{4\pi}}\,\hat p,
\qquad
\hat a^\dagger = \sqrt{\pi}\,\hat x - \frac{i}{\sqrt{4\pi}}\,\hat p,
\]
giving $[\hat a, \hat a^\dagger] = 1$.

The Bargmann ground state $\psi_0(x)$ is determined by $\hat a\psi_0 = 0$:
\[
\Bigl(\sqrt{\pi}\,x + \frac{1}{\sqrt{4\pi}}\,\partial_x\Bigr)\psi_0 = 0
\quad\Rightarrow\quad
\partial_x\psi_0 = -2\pi x \psi_0
\quad\Rightarrow\quad
\psi_0(x) = e^{-\pi x^2}
\]
(unnormalized; with $L^2$-normalization $\psi_0(x) = 2^{1/4} e^{-\pi x^2}$).

The first excited state:
\[
\psi_1(x) = \hat a^\dagger \psi_0 \;\propto\; x \cdot e^{-\pi x^2}.
\]

The Weyl operators in this normalization satisfy
\[
W(u, v) W(u', v') = e^{i\pi(uv' - vu')}\,W(u + u', v + v')

— the standard Tate-Weil metaplectic cocycle. This convention is fixed by
the requirement that the Fourier transform on $L^2(\mathbb{R}, dx)$ has the kernel
$e^{-2\pi i x \xi}$ (= Tate-style normalization), matching the global
