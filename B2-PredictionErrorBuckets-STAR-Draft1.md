## STAR

Imagine an animal in a changing environment.

Sometimes its prediction error is ordinary: the world is as modeled, but the
belief weights are off. It should reweight.

Sometimes the error is geometric: the variable is already present, but through
a nonlinear slow chart. It should rechart.

Sometimes the error is structural: a missing interaction packet explains the
residual. It should learn or admit the packet.

Sometimes the error is temporal: the symmetric state is right but the direction
of flow is wrong. It should open a predictor/current channel.

Sometimes the error is underdetermined: several packets remain plausible. It
should sample.

Sometimes the error is too large to internalize. It should compress or route
externally.

Sometimes the error is not structure at all. It should suppress.

Sometimes the structure is real but disallowed. It should inhibit.

Sometimes the calibration regime has changed. It should rebuild the ledger.

The STAR claim:

\[
\boxed{
\begin{array}{c}
\text{animal cognition is not scalar error minimization;}\\
\text{it is bucketed error routing under boundary evidence,}\\
\text{capacity, current, and governance.}
\end{array}
}
\]

## Minimal Experiment

B2-E1 constructs matched-surprise synthetic episodes. Every episode has roughly
the same scalar residual energy under the retained model, but the true source of
that residual differs.

The episode classes are:

| Episode | True operation |
|---|---|
| parameter drift | reweight |
| nonlinear latent warp | rechart |
| hidden interaction | close |
| reversed temporal flow | predict |
| underdetermined cue | sample |
| too many useful packets | compress |
| random residual | suppress |
| forbidden predictive cue | inhibit |
| regime shift | recalibrate |

The compared agents are:

1. **Scalar surprise agent.** Uses only residual magnitude.
2. **T17 gain-only agent.** Opens structural closure when a boundary gain is
   large.
3. **Post-CBS bucket agent.** Uses retained/chart/packet/current/capacity/noise
   routing features without conformal calibration.
4. **T18 conformal bucket agent.** Uses bucket features plus null calibration
   thresholds and safe defaults.

## Expected Pass Signature

B2-E1 should pass only if all five signatures hold:

1. scalar surprise is matched across episode classes and fails to route;
2. T17 boundary gain separates structure from noise but collapses multiple
   structural buckets into "close";
3. post-CBS bucket features recover chart and current errors separately;
4. T18 conformal gating keeps false structural admission near the declared
   alpha level on noise episodes;
5. ledger error is separable from ordinary retained error.

If the nine buckets are over-specified, the probe should reveal which ones
collapse together.

---

## What Would Falsify the STAR

The STAR should be weakened if:

- scalar surprise routes as well as bucketed features under matched surprise;
- current error is not distinguishable from packet or chart error;
- chart error is not distinguishable from retained reweighting;
- ledger error is not distinguishable from noise or retained error;
- conformal gating destroys routing power or fails to control noise admissions;
- capacity and ambiguity behave identically across evidence scales.
